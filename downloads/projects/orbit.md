# Orbit · 双人事件飞行棋

宋浩个人作品集 | 大学阶段项目 · 持续完善

## 项目背景

围绕数据结构课程中的双人事件棋盘，组织规则、地图事件、存档与历史记录，并持续完善图形界面、双人同步和完整回放。

## 本人职责

负责规则梳理、共享规则层、棋盘交互、对局存档与回放，完成服务器状态裁决、WebSocket 同步及客户端联调。

## 技术栈

TypeScript / Vue 3 / Node.js / WebSocket / 事件日志

## 核心功能

### 规则与模式

双人 100 格棋盘包含炸弹、隧道、黑洞与幸运转盘；支持本地、人机和双客户端联机。

### 同步与恢复

服务端控制骰子和状态，WebSocket 同步结果，刷新恢复玩家身份，房间持久化后可在服务重启时恢复。

### 存档与回放

记录每次投掷和转盘选择，可定位回放；导入先按规则重放，拒绝与日志不一致的棋子状态。

## 实现方法

本地、人机和联机共用规则函数；联机由服务器生成骰子并裁决，行动序号拒绝重复和过时请求。存档按行动日志重放，再核对最终状态。

### 为何保存位置还不足以验证一份存档？

位置可以被任意修改。项目从初始局面重新执行存档中的所有动作，核对回合、胜负、棋子和提示。最终状态若与行动记录不一致，就拒绝恢复并保留当前对局。

## 实践与验证

- 构建成功，20 项规则、存档与联机测试通过。
- 双客户端浏览器实测，双方行动后状态一致，刷新可恢复身份。
- 验证覆盖重复序号、旧连接、写入失败回滚及错误存档拒绝。
