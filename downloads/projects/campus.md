# CampusMate · 校园课表与待办助手

宋浩个人作品集 | 大学阶段项目 · 持续完善

## 项目背景

围绕大学校园中的课程、单双周、学期日程和待办管理，完成 HarmonyOS 原生工程与 Web 交互界面，统一课程和任务的数据规则。

## 本人职责

负责课程与待办功能、页面交互、CSV 导入、离线快照、主题与提醒配置，并完成数据规则、存储流程及构建验证。

## 技术栈

ArkTS / ArkUI / HarmonyOS / JavaScript / 离线存储

## 核心功能

### 课表与任务

课程时间与周次管理、单双周显示、CSV 导入，待办新增、编辑、完成与删除，支持无截止时间任务。

### 离线数据管理

完整备份校验、双槽快照与数据恢复；通过版本检查协调多窗口编辑，让保存与读取保持一致。

### 提醒与主题

支持提前与重复提醒配置、深浅主题，并将原生提醒通道与应用日程数据衔接。

## 实现方法

校验完整快照后再恢复数据；原生存储采用 A/B 双槽提交和损坏回退。页面保存失败时保留编辑内容，检测跨窗口修改并拒绝旧数据覆盖。

### 如何避免一次失败保存损坏已有数据？

原生快照先写入非活动槽、落盘并读回核对，之后才切换活动指针。若写入或指针提交失败，保留之前可读的数据；浏览器端同时检查版本，阻止旧窗口覆盖新记录。

## 实践与验证

- 49 项规则与服务测试通过，覆盖课程、待办、导入、快照与提醒配置。
- 浏览器完整验证课程与待办操作、备份恢复、主题和多窗口协同。
- HarmonyOS ArkTS 编译与 HAP 打包成功，桌面和手机布局完成验证。
